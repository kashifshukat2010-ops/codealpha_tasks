# Phishing Awareness Training 🎣

**CodeAlpha — Cyber Security Internship, Task 2**

An interactive training module as a single HTML file — open it in any browser,
no server needed. Covers: what phishing is, 6 email red flags, fake-website URL
tricks, social engineering tactics, best practices, real-world examples, and a
5-question interactive quiz with instant feedback.

## Open it

Just double-click `phishing-awareness-training.html` — or serve it:

```bash
cd task2-phishing-training
python3 -m http.server 8000
# open http://127.0.0.1:8000/phishing-awareness-training.html
```

## Contents

1. **What is phishing** — email/spear phishing, smishing, vishing
2. **6 red flags** — sender spoofing, urgency, generic greeting, suspicious
   links, malicious attachments, bad grammar/design
3. **Fake websites** — typosquatting, subdomain tricks, HTTPS myth, homographs
4. **Social engineering tactics** — authority, urgency, greed, trust, helpfulness
5. **Best practices** — hover-before-click, MFA, never share OTPs, verify
   senders, report incidents
6. **Real-world examples** — bank SMS scam, spear-phishing case, fake courier SMS
7. **Interactive quiz** — 5 questions, instant right/wrong feedback + score
